# Global Development Indicators Analysis Using World Bank Data – Power BI Project

This repository contains a **Global Development Indicators Analysis Project** built with **Microsoft Power BI**.  
The project focuses on analyzing World Bank development indicator data and presenting meaningful insights through interactive dashboards and visual reports.

## Project Overview

The main objective of this project is to analyze global development indicators using World Bank data.  
The dashboard helps users understand country-level development patterns, economic trends, demographic changes, and comparative insights across different regions.

## Key Features

- Interactive Power BI dashboard for global development analysis
- Country-wise and region-wise indicator comparison
- Economic, demographic, and development trend visualization
- Clean and organized Power BI project structure
- Data-driven insights using charts, cards, maps, and filters
- Useful for research, academic analysis, reporting, and portfolio presentation

## How to Use

1. Download or clone this repository:

```bash
git clone https://github.com/sudeepmondal/Global-Development-Indicators-Analysis-Using-World-Bank-Data__PowerBI-Project.git
```

2. Open the project folder:

```bash
cd Global-Development-Indicators-Analysis-Using-World-Bank-Data__PowerBI-Project
```

3. Go to the main project directory:

```bash
cd Power-BI-World-Bank-Data-Analysis
```

4. Open the Power BI `.pbix` file using **Microsoft Power BI Desktop**.

5. Refresh the dataset if required.

6. Explore the dashboard visuals, filters, charts, and maps.
